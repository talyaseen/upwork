# upwork

Project index and portfolio repo for Talal Alyaseen (AI-First Software Engineer | DevOps). Each project below lives on its own branch of this repo and is deployed live.

**Portfolio: [https://joltingbolt.com](https://joltingbolt.com)**

## Projects

### 1. AI Dev-Tools Demo
An AI-First chat assistant with RAG (grounded Q&A with citations), a code-review skill, and a Mermaid diagram generation skill, served by a self-hosted 7B model on dual GPUs with a custom safety-tuned guard layer.

- Live: [https://chat.joltingbolt.com](https://chat.joltingbolt.com)
- Source: [fastapi-ai-devtools-demo](https://github.com/talyaseen/upwork/tree/fastapi-ai-devtools-demo)

### 2. AURUM - Rate Intelligence for Luxury Hotels
A hotel rate intelligence platform (Next.js + Supabase) with authentication and a personal saved-rates collection.

- Live: [https://hotel-rate-intelligence.vercel.app](https://hotel-rate-intelligence.vercel.app)
- Source: [hotel-nextjs-supabase](https://github.com/talyaseen/upwork/tree/hotel-nextjs-supabase)

### 3. Infrastructure as Code
A reference Ansible deployment (Cloudflare edge, mTLS reverse proxy, systemd hardening) used to deploy the demos above.

- Source: [ansible-hardening-iac](https://github.com/talyaseen/upwork/tree/ansible-hardening-iac)
